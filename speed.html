What is Speed?

Speed is a measure of how fast an object is moving. More precisely, it tells you the distance an object travels in a certain amount of time.

The formula for speed is :

Speed = Distance / Time

Where:

  • Distance is how far the object has moved.
  • Time is how long it took to move that distance.

For example, if a car travels a distance of 100 kilometers in 2 hours, the speed would be calculated as:

Speed = 100 km / 2 hours = 50 km/h


Common units of speed :

  1. Kilometer per hour ( km/h ).
  2. Miles per hour ( mi/h or mph ).
  3. Knot ( Kt )
  4. Mach ( M or Ma )
