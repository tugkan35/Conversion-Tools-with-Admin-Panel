What is Temperature?

Temperature is a measure of how hot or cold something is. More scientifically, it reflects the average kinetic energy of the particles (like atoms and molecules) in a substance.

  • If the particles are moving fast, the temperature is high (hot).
  • If the particles are moving slow, the temperature is low (cold).

Temperature is different from heat:

  • Temperature measures the intensity of heat (how hot something is).
  • Heat is the energy transferred from one object to another because of a temperature difference.

Fahrenheit to Celsius :

°C = (°F - 32) / 1,8

Celsius to Kelvin :

K = °C + 273,15

Important Temperature conversions :

0 Celsius ( °C ) is equals to 32,00 Fahrenheit ( °F )

0 Celsius ( °C ) is equals to 273,15 Kelvin ( K )

0 Fahrenheit ( °F ) is equals to -17,78 Celsius ( °C )

0 Fahrenheit ( °F ) is equals to 255,37 Kelvin ( K )

0 Kelvin ( K ) is equals to -273,15 Celsius ( °C )

0 Kelvin ( K ) is equals to -459,67 Fahrenheit ( °F )
